Maison Encore – Web Project
Part 2: CSS & Responsive Design

Project Overview
This project is part of the Website Design assignment. The goal of Part 2 is to enhance the visuals and responsiveness of the website created in Part 1. We achieved this by implementing a consistent design system, applying visual styles, and ensuring the site adapts across desktop, tablet, and mobile devices.
The website was developed for Maison Encore, a fictional boutique retail store.

Design Implementation
1. External Stylesheet
•	Created style.css and linked it to all HTML files.
•	Ensured consistent naming conventions.
2. Base Styles
•	Applied CSS reset for consistent cross-browser rendering.
•	Set global styles for font-family, base font size, margins, and padding.
3. Typography
•	Headings styled with a modern serif font (Georgia) for elegance.
•	Body text styled with a clean sans-serif (Arial) for readability.
•	Adjusted line-height and spacing for better readability.
4. Layout Structure
•	Used Flexbox for navigation and page alignment.
•	Content-centered horizontally.
•	Responsive grid layout applied to the shop page for product listings.
5. Visual Styles
•	Applied consistent colour palette (from proposal):
o	Primary: Deep Crimson (#430000)
o	Accent: Gold (#c5a880)
o	Neutral: Black (#0000)
o	Background: White (#ffff)

•	Added borders and box-shadows for product cards.
•	Hover and focus states added for navigation links and buttons.

Responsive Design
Breakpoints
•	Desktop: ≥1200px (multi-column layout).
•	Tablet: 768px – 1024px (2-column layout).
•	Mobile: ≤480px (single-column layout).
Relative Units
•	Used em and % for font sizes, spacing, and widths.
Responsive Images
•	Implemented scaling images with max-width: 100% and height: auto.
